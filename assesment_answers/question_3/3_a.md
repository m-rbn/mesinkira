# Front-End Integration with AWS Amplify
AWS Amplify looks like a great option to deploy a front end. 
As an AWS products, it's safe to assume it supports integration of other AWS services.
In terms of security, it's also easy to set up secure sign-in authentication and also support multi-factor authentication.
Being an AWS product, another obvious benefit is it's a managed hosting service so resources can be scaled up anytime it's needed.
Another great feature I can see is the CI/CD workflow support, I like the simplicity of pushing into the repo then Amplify will handle the auto-deploy.
